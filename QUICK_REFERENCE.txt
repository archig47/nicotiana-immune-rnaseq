- ✅ All samples >10M reads
- ✅ GC content 45-48%

After Trimming:
- ✅ Read retention >70%

After Alignment (STAR):
- ✅ Mapping rate >80%
- ✅ Strandedness confirmed (reverse)

After Counting (featureCounts):
- ✅ >95% reads assigned
- ✅ 37,919 genes detected

After DESeq2:
- ✅ PCA: mock vs. Pst separated
- ✅ DEGs: ~2-20% of genes
- ✅ Top DEGs: MAPK, WRKY, NLR, PR genes UP ✓

## Parameter Testing Framework

The agent tests these parameters and picks the best:

| Tool | Option A (Specified) | Option B (Test) | Option C (Test) |
|------|---------------------|-----------------|-----------------|
| **Trim Galore** | Q20/30/3 | Q15/25/3 | Q25/35/3 |
| **STAR** | genome SAindex=14 | - | - |
| **featureCounts** | -s 2 (reverse) | -s 1 (fwd) | -s 0 (un) |
| **DESeq2 design** | ~ condition | ~ 1 + cond | ~ cond * time |
| **DESeq2 threshold** | \|FC\|≥1, p<0.05 | \|FC\|≥0.58 | \|FC\|≥1, p<0.1 |

Agent picks best based on:
- Biological sanity (expected genes?)
- Statistical quality (clean separation?)
- Computational efficiency

## What Gets Tested Biologically

The agent validates:
- **N. benthamiana specifics**: GC 45-48%, genome 3.5Gb, high repeats
- **Pst infection**: PTI (1-2h) + ETI (2-4h) at 6h
- **Expected DEGs**: MAPK, WRKY, NLR, PR genes should be UP
- **Unexpected DEGs**: Random genes UP/DOWN = batch artifact (flag it)
- **PCA clustering**: Replicates together, treatment separated

---

## Error Handling

| Problem | Fix |
|---------|-----|
| Read retention <70% | Loosen quality: --quality 15 |
| Mapping <75% | Lower SAindex to 13 |
| %Assigned <85% | Verify strandedness is -s 2 |
| DEGs 0 or >50% | Check PCA for batch effects |
| Replicates scattered | Check for outliers, remove if justified |
